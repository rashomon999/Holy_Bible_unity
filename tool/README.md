Scripts que se usaron una sola vez para sacar el contenido de las escenas de
Unity y generar `assets/data/passages.json`.

    python3 tool/extract_from_unity.py

Esperan las escenas en la ruta que está escrita dentro del script (glob de
`Assets/Scenes/*/*.unity`). Se dejan aquí como registro de de dónde salieron
los datos; la app no los necesita para correr.
